# 100 Days of Research Papers

A public commitment: **read one AI/ML research paper (nearly) every day for 100 days**, and write up what I actually learned — in plain language, with links and takeaways — so the ideas stick and anyone else can follow along.

## Why

Reading papers is the fastest way to move from *using* models to *understanding* them. Each note answers three things:

- **Why I read it** — the motivation and the problem it solves
- **What I understood** — the core ideas, in my own words
- **Why it matters** — how it connects to modern LLMs and my other work in this repo

## How to use this

- Notes are numbered by day: `NN-Day-<PaperName>.md`.
- Each file is self-contained — open any one and read top to bottom.
- New to the field? Read in order; the early papers are the foundations everything else builds on.
